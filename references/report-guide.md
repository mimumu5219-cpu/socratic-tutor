# 图片学习报告生成规范

每次学习结束（或暂停经用户同意）时，把本次学习成果做成一张**海报质感、文字精确**的图片报告交付给用户。

## 1. 触发时机

- **全部模块讲完**：自动生成并交付，不询问。
- **用户暂停**：先询问「要不要生成一张本次学习的图片报告？」，用户同意才生成；不同意则跳过。

## 2. 报告内容（严格三部分，不添加无关内容）

数据来源：以刚写入的存档 `~/.socratic-tutor/存档/<主题>.md` 为准（兼容旧路径 `~/DoubaoWork/学习存档/`）。**图片上的文字必须与存档完全一致**，不得改写、润色或编造。

1. **基本信息**：主题、人设、日期（当天）、完成状态（已完成 / 进行中）。
2. **模块进度与掌握度**：每个模块的名称、状态（已讲 / 未讲）、掌握度 0-100（未讲用「-」）。掌握度做可视化：
   - ≥90：绿色，表示掌握到位
   - 70-89：黄色，表示有模糊点
   - <70：橙红色，表示需重讲
3. **薄弱点清单**：从存档「薄弱点清单」提取，按模块逐条列出。

## 3. 生成方式（海报排版 + 精确文字）

- **首选：HTML 精确排版渲染为图片**。用 HTML/CSS 做出海报质感（渐变背景、卡片、进度条、装饰元素），图片内所有文字必须是存档真实数据，做到零误差。
- 环境存在 doubao-creative-design 等设计/渲染工具时，按其 HTML 渲染、自检与交付规范执行（数据是纯文本内容时优先走 Coding 精确排版路径）。
- **备选：仅当环境无法 HTML 渲染时**才使用文生图；必须把关键文字（主题、模块名、掌握度分数）逐字放进生成指令，生成后逐字核对，有误则重生成或用 HTML 兜底，绝不交付文字出错的报告。

## 4. 版式建议

- 画幅：竖版 3:4（适合手机查看与分享）。
- 配色跟随人设：
  - 温柔学姐型 → 柔和暖色（米白/浅粉）
  - 毒舌教授型 → 深色高对比（墨蓝/白）
  - 幽默损友型 → 活泼撞色
  - 理性导师型 → 冷静蓝灰
  - 元气陪练型 → 明亮活力色
  - 冷峻专家型 → 黑白简约
- 布局：顶部标题区（主题 + 人设 + 日期 + 状态）→ 中部模块进度区（每模块一行：名称 + 状态 + 掌握度进度条）→ 底部薄弱点区。

## 5. 交付

- 图片生成后以媒体卡片形式直接展示给用户（图片类产物走媒体交付，不用普通链接）。
- 图片文件同时存入 `~/.socratic-tutor/存档/`，与 Markdown 存档同名，如 `<主题>-报告.png`。
- 若本次是暂停后待续学：状态标「进行中」，薄弱点区突出未学透的模块，方便下次恢复时对照。
