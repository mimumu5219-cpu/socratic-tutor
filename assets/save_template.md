# 学习存档模板

每次学习结束或暂停时，按以下格式写入 `~/DoubaoWork/学习存档/<主题>.md`（目录不存在则先创建）。
下方为模板与一份已填充示例。

---

## 模板

```markdown
# 学习存档：<主题>

- 创建日期：<YYYY-MM-DD>
- 最近更新：<YYYY-MM-DD>
- 人设：<人设名>
- 材料来源：<上传材料 / 网络检索 / 混合>
- 状态：<进行中 / 已完成>

## 模块进度

| # | 模块名 | 状态 | 掌握度(0-100) | 薄弱点 |
|---|--------|------|--------------|--------|
| 1 | <模块1> | <未讲/已讲> | <评分或 -> | <无/描述> |

## 薄弱点清单

- <模块>：<薄弱点描述>

## 下次续接点

- 从模块 <N>「<模块名>」继续
- 待解决：<上次没讲清/没答上的点>

## 关键概念速记

- <概念>：<一句话>
```

---

## 已填充示例

```markdown
# 学习存档：经济学中的供需关系

- 创建日期：2026-10-29
- 最近更新：2026-10-29
- 人设：毒舌教授型
- 材料来源：网络检索
- 状态：进行中

## 模块进度

| # | 模块名 | 状态 | 掌握度(0-100) | 薄弱点 |
|---|--------|------|--------------|--------|
| 1 | 需求曲线 | 已讲 | 85 | 需求弹性概念模糊 |
| 2 | 供给曲线 | 已讲 | 90 | 无 |
| 3 | 均衡价格 | 未讲 | - | - |

## 薄弱点清单

- 需求曲线：需求的价格弹性，弹性>1 与 <1 的含义分不清

## 下次续接点

- 从模块 3「均衡价格」继续
- 待解决：先复习需求弹性，再讲均衡

## 关键概念速记

- 需求曲线：价格↑ 需求↓
- 供给曲线：价格↑ 供给↑
- 均衡价格：需求与供给相交处
```
