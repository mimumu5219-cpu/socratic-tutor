# Socratic Tutor · 苏格拉底式对话学习 Skill

一个让 AI 扮演苏格拉底式导师、通过「讲解 + 提问」把任意主题教到真正理解的可安装 Skill。**平台无关，适用于所有支持 Skill 机制的 AI 工作台。**

## 核心特点

- **AI 主讲**：把主题拆成有逻辑顺序的小模块，逐个讲解，螺旋上升
- **双语言讲解**：每个模块用「专业语言 + 通俗语言」各讲一遍
- **两段式提问**：① 检验已讲内容的理解（模块掌握度 0-100 评分）② 探测对下一模块的预期，动态调整讲解粒度
- **实时查证**：关键概念现场联网验证，不编造来源，每 10 回合总结纠偏防幻觉
- **人设系统**：6 张综合人设卡（温柔学姐 / 毒舌教授 / 幽默损友 / 理性导师 / 元气陪练 / 冷峻专家），支持扩展
- **存档续学**：暂停即存档（Markdown），说「继续学 X」随时恢复进度与薄弱点
- **图片学习报告**：学完自动生成海报质感、文字精确的学习报告图（模块进度 + 掌握度 + 薄弱点）

## 快速开始

在任意支持 Skill 机制的 AI 工作台 / 助手中，直接对助手说：

- 「我想学经济学中的供需关系」
- 「教我 Python 列表」
- 「继续学供需关系」（恢复上次学习进度）

Skill 会自动进入学习流程：**检查存档 → 询问是否上传材料 → 选择人设 → 拆分模块 → 逐模块讲解与提问**。

## 学习流程

```
开场（恢复存档 → 询问材料 → 选择人设）
   ↓
规划模块（拆成 3-8 个有逻辑顺序的小模块）
   ↓
逐模块循环：
  讲解前实时查证 → 专业+通俗双语言讲解 → 提问①理解检验(模块评分)
  → 提问②下一模块预期 → 调整粒度
   ↓
每 10 回合总结已讲内容，纠偏防幻觉
   ↓
结束/暂停：写入存档 → 生成图片学习报告
```

## 安装

1. 将本仓库的 `socratic-tutor/` 文件夹复制到你所用 AI 工作台的 skills 目录（常见位置：`~/.user_skills/`、`~/.claude/skills/`、`~/.cursor/skills/` 或工作区 skills 目录，以你使用的平台为准）
2. 重启 / 刷新工作台，使其加载该 Skill
3. 直接说出学习意图（如「我想学 XX」）即可开始

## 数据与存档

- 学习进度存档：`~/.socratic-tutor/存档/<主题>.md`
- 图片学习报告：`~/.socratic-tutor/存档/<主题>-报告.png`
- 存档内容：模块进度、掌握度评分（0-100）、薄弱点清单、下次续接点
- 旧版存档路径 `~/DoubaoWork/学习存档/` 仍兼容读取

## 平台兼容性

- 本 Skill 不依赖任何特定 AI 平台
- 依赖环境提供的能力（网络检索 / 视频搜索 / 图片渲染）按需降级：有则增强讲解效果，无则保持纯文字讲解
- 存档路径与工具调用均为跨平台通用约定，可直接在各工作台使用

## 使用场景

- 系统学习新领域（备考、入门、进阶）
- 围绕上传材料（课本 / 文档 / 笔记）逐节精读
- 复习与续学：暂停后随时恢复，重点攻克薄弱点
